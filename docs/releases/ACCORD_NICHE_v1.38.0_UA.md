# ACCORD NICHE v1.38.0 — сайт: плавні сучасні анімації

Шар руху для головного сайту, ширший за пункт W-36 аудиту `ACCORD_NICHE_WEBSITE_UI_UX_AUDIT_2026-11-18`. Логіка магазину не змінювалась: кошик, ціни, оформлення, SEO.

## Принципи

- Рухаються **лише `transform` і `opacity`**, тож верстка не зсувається. Виміряний CLS під час завантаження й прокрутки: **0,000**.
- **Нічого не ховається** без JavaScript, у браузерах без потрібних можливостей і на першому екрані: анімація лише прикрашає те, що й так видно.
- Із системним налаштуванням **«зменшити рух»** анімацій немає зовсім, ні переходів, ні появи: перевірено, що жоден елемент не анімується.
- Криві руху сучасні: швидкий старт і м'яке приземлення (`cubic-bezier(.16,1,.3,1)`), невеликий «пружний» перехід для бейджів. Тривалості задані токенами `--motion-fast/soft/slow/reveal` у `motion.css`.

## Що рухається

- **Переходи між сторінками.** Через View Transitions API стара сторінка тихо зникає, нова підіймається. Шапка має власну назву переходу й стоїть на місці. У браузерах без API сторінка просто проявляється. Перемикання об'єму на сторінці товару переходом не вважається.
- **Перший екран.**
  - Надзаголовок, заголовок, опис і кнопки з'являються каскадом.
  - Літера «A» (або фото героя) повільно проявляється.
- **Поява при прокрутці** (`website/src/motion.js`, IntersectionObserver):
  - заголовки секцій, картки товарів, кроки «Як це працює», картки блогу, блоки сторінки товару й оформлення підіймаються, коли доходять до екрана;
  - у сітці карток діє каскадна затримка до 350 мс;
  - після появи службові класи знімаються, тож наведення на картку працює зі своєю швидкістю.
- **Мікровзаємодії.**
  - Картка при наведенні підіймається на 4 px з м'якою тінню, а фото трохи збільшується (лише для точного вказівника, не на сенсорних екранах).
  - Підкреслення пунктів меню виростає зліва.
  - Стрілка «Переглянути всі →» зсувається.
  - Хрестик на чипі фільтра повертається.
  - Кнопки злегка «натискаються» (`scale(.97)`).
  - Лічильник кошика «підстрибує» при зміні.
  - Обраний об'єм на сторінці товару ледь пружинить.
- **Кошик і діалоги.**
  - Кошик виїжджає справа, а тло затемнюється з легким розмиттям.
  - Рядки кошика з'являються каскадом.
  - Довідкові діалоги проявляються з невеликим підйомом.
- **Каталог і оформлення.** Плавно з'являються панель фільтрів на телефоні, чипи, підказки Нової пошти, згорнутий підсумок, довідки біля згоди, повідомлення й примітки рядків кошика.
- **Завантаження.** Крапка м'яко «дихає», а не блимає.

## Тести

`qa/browser-website-motion.mjs` (у `qa/run-browser.sh`), 15 перевірок:
- на першому екрані нічого не сховано;
- блоки нижче чекають і з'являються;
- після прокрутки все видно, службові класи зняті;
- CLS < 0,05;
- шапка не бере участі в переході;
- навігація через перехід завершується;
- кошик виїжджає, лічильник пружинить;
- зі «зменшенням руху» нічого не ховається й нічого не анімується.
