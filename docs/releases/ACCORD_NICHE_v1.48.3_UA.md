| `asyncio: Future exception was never retrieved … gaierror(-3, 'Temporary failure in name resolution')` (5 разів) | Коли Redis був недоступний (~2 хв 26.11), redis-py обривав підключення за тайм-аутом, але DNS-запит продовжувався у фоні; його помилку ніхто не забирав, і asyncio писав ERROR через ~20 с. | `shop/redis_dns.py`: хост Redis резолвиться до підключення, а результат фонового DNS-запиту завжди забирається. | `GET /api/integrations/salesdrive/dictionaries → 400` | Панель запитувала довідники SalesDrive щоразу при відкритті «Інтеграцій», навіть коли SalesDrive не налаштовано, і показувала червону помилку. | Автозавантаження — лише коли задано субдомен і API-ключ. Кнопка «Оновити дані SalesDrive» лишилась. |

- `POST /api/web/analytics/visit → 403` (3 рази) — запити з IP дата-центрів (Scaleway, AWS) без правильного `Origin`.
  Це боти; захист працює як задумано, справжні візити сайту й Android-застосунку записуються (204).
- `GET /api/auth/session → 401` (2 рази) — панель перевіряє сесію до входу; після входу 200.
- Сама недоступність Redis 26.11 11:28–11:30 — проблема інфраструктури (контейнер Redis або Docker DNS),
  не коду. Магазин продовжував працювати: live-події йшли локальним шляхом, планувальник лишився запасним
  виконавцем синхронізації SalesDrive.
