# ACCORD NICHE v1.6.1 — пароль системного адміністратора

Мінімум DASHBOARD_PASSWORD змінено на 8 символів у доменному preflight, перевірках Docker/API startup та звіті стану налаштувань. Паролі довші за 8 символів також приймаються; автоматичне створення випадкового пароля та перевірки шаблонних значень збережено.

Наявний пароль не перезаписується. Для облікових записів адміністраторів і менеджерів у панелі залишається їхня окрема політика — мінімум 12 символів.

Після заміни вихідних файлів:

```bash
python3 scripts/setup_domains.py --check
bash deploy/domains.sh up -d --build
```

Міграцій БД немає. Збережіть .env.domains і чинний Compose namespace.

Перевірки: 207 pytest-тестів і 4 subtests пройдено, включно з межами 7/8 символів для setup/API та Docker preflight. Python compileall пройшов.
