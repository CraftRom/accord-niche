# ACCORD NICHE v1.24.0 — промосторінки вирізано остаточно

Продовження v1.23.0: від промосторінок в ACCORD не лишилось нічого, включно з даними. Нова міграція: head **`c8f1e5a3d702`**.

## Що змінено

- **Міграція `c8f1e5a3d702`:**
  - видаляє таблиці `promo_landing_pages` і `promo_landing_daily_stats` разом з усіма сторінками та статистикою;
  - видаляє з налаштувань зашифрований токен і акаунт Cloudflare (`promo_cloudflare_api_token`, `promo_cloudflare_account_id`), якими користувались лише промосторінки.
  - `downgrade` відтворює лише порожні таблиці: дані з бази повернути неможливо.
- Видалено моделі `PromoLandingPage` і `PromoLandingDailyStat`.
- Журнал безпеки допускає лише простір подій `security.*`.

Історична міграція `c6a72f19e301`, яка колись створила ці таблиці, лишається в ланцюжку: без неї неможливо послідовно оновити стару базу. Старі релізні нотатки й звіти аудиту не переписувались, бо це історія змін.

ELFAR не змінювався. `connect_elfar_edge.py` і далі перестворює власний контролер **ELFAR** разом із його nginx, бо вони ділять простір процесів.

## ⚠️ Перед оновленням

Міграції запускаються автоматично під час `connect_elfar_edge.py`. Після цього дані промосторінок буде видалено назавжди. Якщо вони можуть знадобитися, спершу зробіть копію:

```bash
cd /opt/accord-niche
bash deploy/backup.sh
python3 scripts/connect_elfar_edge.py
python3 scripts/accord_release_check.py
```

Копія БД, зроблена до оновлення, ще міститиме ці таблиці. Якщо таку копію відновити, автоматичні міграції видалять їх знову.
