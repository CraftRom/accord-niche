# ACCORD NICHE v1.12.0 — плавність інтерфейсу та футер

Оновлено публічний сайт, його версія — **1.2.0**. Збережено всі виправлення v1.11.2.

## Анімації

- М’яка поява сторінок і карток без послідовних затримок. Звичайне фонове оновлення даних не перезапускає появу змонтованих елементів.
- Невеликий рух першого екрана: до 7 px, без стрибків і пружин.
- Кошик відкривається з коротким зсувом 20 px; інформаційні діалоги та пошук з’являються м’яко. Закриття залишається негайним, щоб зберегти роботу Escape та відновлення фокуса.
- Тонка лінія під пунктом навігації при наведенні або клавіатурному фокусі.
- Плавна зміна кольорів кнопок і полів. Картки піднімаються на 2 px, зображення збільшуються лише на 2,5%. Такі hover-ефекти працюють лише для точного вказівника з підтримкою наведення; на сенсорних екранах картка залишається стабільною.
- Тривалість більшості ефектів — 180–360 мс; поява першого екрана — до 560 мс.
- Немає нових залежностей, таймерів анімації чи обробників прокручування. Контент не приховується в очікуванні виконання JavaScript або появи у viewport.
- При `prefers-reduced-motion: reduce` анімації, переходи, рух карток і плавне прокручування вимкнено, включно з наявним індикатором завантаження.

## Футер

Кореневий контейнер має вертикальний flex-макет і мінімальну висоту екрана: `100vh` із сучасним `100dvh` для мобільних браузерів. Основний контент заповнює вільну висоту, футер відсувається вниз.

На коротких сторінках футер знаходиться біля нижнього краю екрана. На довгих сторінках він розміщується після контенту й доступний прокручуванням. Він не перекриває форми, кнопки чи текст. Правило спільне для каталогу, блогу, профілю, оформлення, успішного замовлення та сторінки 404. Збережено ширину сторінок `.shell`; висота документа може зростати при збільшенні тексту або відкритті клавіатури. До нижнього відступу футера додано системний safe-area inset, коли браузер його надає.

## Перевірки й встановлення

- Production-збірка сайту успішна; **38 JS/DOM-перевірок пройдено**, включно з оформленням, кошиком, Escape і фокусом діалогів, блогом та історією покупок.
- CSS виробничої збірки розбирається без помилок. Перевірено застосування вертикального flex-макета, `100dvh`, розтягування основного контенту та автоматичного відступу футера. DOM-перевірка не є вимірюванням реальної геометрії браузера; огляд нової збірки на фізичних телефонах не виконувався.
- Backend, міграції, dashboard, Mini App та сценарії доменного розгортання не змінювалися. Повторні серверні тести для цих незмінених частин не запускалися.
- Нові зміни ще не встановлені на робочому VPS.

Розпакуйте повний архів у `/opt/accord-niche`, зберігши `.env.domains` і поточні дані. Від root:

```bash
python3 /opt/accord-niche/scripts/connect_elfar_edge.py
```
